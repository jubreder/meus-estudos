# diario de bordo - registro de evolução

esse espaço foi criado para registrar diariamente/semanalmente meus aprendizados, rotina de estudos e a evolução prática da minha jornada para me tornar uma Desenvolvedora Full Stack.

## objetivos deste diario

documentar a evolução, fixar conhecimento, mapear dificuldades e criar consistência.

## índice por mês

abaixo está o histórico de registros organizados cronologicamente:
| mês / ano | status | foco principal | link para os registros |
| :--- | :---: | :--- | :--- |
| novembro/2026 | em andamento | JavaScript, CSS, HTML, estruturas web | [acessar novembro](./novembro-2026.md) |

## estrutura padrão dos registros

para manter a consistência, cada entrada nos arquivos mensais segue o formato:

```markdown
### dd/mm/aaaa - [titulo / topico estudado]

- o que fiz: breve resumo das aulas assistidas, leituras ou práticas realizadas
- aprendizado principal: conceito-chave que aprendi no dia
- dificuldades/erros: bugs enfrentados e como foram resolvidos
- links e referencias: links para os trechos de codigo, repositorios ou cursos
```
